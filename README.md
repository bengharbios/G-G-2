# يلا لايف 🎲 — غرف صوتية وهدايا ولودو

تطبيق دردشة صوتية عربي مستوحى من أسلوب Yalla Ludo: غرف صوتية بمقاعد ميك، هدايا فاخرة برسوم SVG متحركة، اقتصاد كامل (ذهب + مجوهرات + مستويات + ألقاب ثروة)، ولعبة **لودو حقيقية** 2-4 لاعبين بمحرك سيرفر موثوق.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000` في المتصفح. لدخول أكثر من لاعب: افتح التطبيق في عدة تبويبات أو أرسل الرابط لأصحابك على نفس الشبكة (استخدم IP جهازك بدل localhost).

> للصوت داخل الغرفة يلزم الاتصال عبر `localhost` أو `https` (قيود المتصفح على المايك).

## الميزات

| الميزة | التفاصيل |
|---|---|
| 🎙️ غرف صوتية | 8 مقاعد ميك، صوت مباشر WebRTC (Mesh + Perfect Negotiation) |
| 🎁 هدايا | 17 هدية مرسومة SVG يدوياً (وردة، تاج، سيارة، يخت، قصر، صاروخ...) بأنيميشنات مختلفة حسب الفئة |
| 💰 اقتصاد | ذهب 🪙 + مجوهرات 💎 (1 مجوهرات = 10,000 ذهب) + مكافأة يومية + تبادل |
| ⭐ مستويات | 50 مستوى خبرة + 8 ألقاب ثروة حسب الإنفاق |
| 🎲 لودو | رقعة 15×15، 4 قطع، فتح بستة، أسر، مربعات آمنة، ثلاث ستات، بوتات بذكاء بسيط، حارس ضد التجمّد |
| 🐍 ألعاب أخرى | سلم وثعبان + المسبحة (كل 33 تسبيحة = مكافأة) |
| 🤖 بوتات | زر "بوت" في أي غرفة — يدخل ويتكلم ويلعب |
| 💬 أخرى | رسائل خاصة، لوحة صدارة (الأغنى/المستويات) |

## البنية

```
server/
  index.js   — Express + Socket.IO: الغرف، المقاعد، الشات، الهدايا، الإشارات، الألعاب
  ludo.js    — محرك اللودو (Authoritative): النرد، الأسر، البوتات، الحارس
  state.js   — الحالة في الذاكرة (المستخدمون، الغرف، الاقتصاد)
client/
  index.html — كل الشاشات (دخول، رئيسية، غرفة، رسائل، حسابي)
  css/       — ثيم فاتح بألوان يلا (أزرق/أخضر/ذهبي)
  js/        — app (المنطق)، ludo (لوحة Canvas)، gifts (رسوم SVG)، rtc (الصوت)، games
```

## التحويل إلى Android و iOS

المشروع جاهز ليُغلَّف بـ [Capacitor](https://capacitorjs.com) دون تعديل:

```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/android @capacitor/ios
npx cap init "YallaLive" "com.yourname.yallalive" --web-dir client
npx cap add android
npx cap add ios
```

لكن ليعمل على الأجهزة الحقيقية يجب تغيير عنوان السوكت في `client/js/app.js` من `io()` إلى عنوان سيرفرك العام (مثل `io('https://your-server.com')`)، ونشر السيرفر على استضافة (VPS مثل DigitalOcean أو Railway). للصوت عبر الإنترنت على نطاق واسع يُنصح لاحقاً بإضافة خادم TURN (coturn) لعبور NAT.
